Ativar marca, modelo e preços reais

Grátis (Gemini): aistudio.google.com/apikey → “Create API key” → cole aqui. Não precisa cartão.
Grátis (OpenRouter, reserva): crie conta em openrouter.ai → Keys → Create key. Identifica o produto, mas não pesquisa preços.
Sem chave o app reconhece tipo e marca pela IA grátis do aparelho. Com uma chave de IA na nuvem ele acha o modelo exato, as especificações e as ofertas reais com preço. Cole uma vez só: fica salva só neste celular.

Banco de dados (Supabase)

Com o Supabase ligado, contas, pedidos, ofertas e avaliações ficam compartilhados entre todos os celulares. Sem ele o app roda em modo demonstração.
